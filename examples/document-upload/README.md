# Document upload example

Minimal ASP.NET Core sample for thin Controllers, DTOs outside Services, upload
orchestration in a Service, options validation and category-key normalization.
It is a disposable learning consumer, not a production API and not installed by
native skill copy.

```sh
dotnet test examples/document-upload/DocumentUpload.slnx -c Release
```

This sample has no authentication provider; consumers must add their approved
authentication and authorization contracts themselves.
