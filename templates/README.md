# Backend project onboarding

This starter is created only when the project has no README. Replace this title
with the application's name and describe its purpose and local run command.

The development foundation is installed under `.backend-common/`. Start with
`.backend-common/docs/getting-started.md` for target selection and validation.

```sh
node .backend-common/scripts/completion-gate.mjs
```

Before sharing this README, document the SDK from global.json, solution path,
local dependencies, non-secret configuration keys, API run URL and test commands.
Record the verified baseline in `memory/PROJECT.md`; keep durable choices in
`memory/DECISIONS.md`. Never include actual credentials.

Application docs, SQL schema, authentication, environments and deployments belong
to this project. Common updates do not replace this README.
