# Decisions

Record only approved, durable choices. This template makes no architecture
decision for an existing application. ACTIVE entries apply; SUPERSEDED entries
remain as history with a replacement reference. Proposed entries are not approval.

For each decision record:

- ID and title.
- Date and status (PROPOSED, ACTIVE or SUPERSEDED).
- Decision, scope and reason.
- Consequences, including security/data/compatibility tradeoffs.
- Evidence in source/docs and the approval that established it.
- Replaces/replaced-by ID when applicable.

Do not duplicate PROJECT.md or include secrets. Update this repository file only
when the authorized task changes a durable decision.
